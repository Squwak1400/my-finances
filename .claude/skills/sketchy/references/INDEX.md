# Template index

Credit: these templates are from **gpt-image-2** by **ConardLi** (https://github.com/ConardLi/garden-skills), under the MIT licence. See `../ATTRIBUTION.md`.

The templates are the original gpt-image-2 files, mostly written in Chinese with English prompt bodies. Read only the one you need.
Every template was written for an image model. In this skill a filled template is a **brief**, and the brief is built in code (see `../code/translate.md`).
The "In code" notes say what each category usually turns into.

Method: `prompt-writing.md` explains how to decide which fields to ask about, which to default and which to randomise, and how to turn a one-off into a reusable template.

## infographics/: start here for most sketchy work
- `hand-drawn-infographic.md`: **the core sketchy style.** It covers a bullet-journal page, wobbly lines, fills that stop short of the outline, hand lettering, number badges, doodles and an optional mascot. It has palettes (macaron, morandi, kraft, chalkboard, pencil-only) and variants.
- `bento-grid-infographic.md`: 6–9 modules of mixed sizes, like iOS widgets or a Notion dashboard.
- `comparison-infographic.md`: A vs B, plans and tiers, myth vs fact.
- `step-by-step-infographic.md`: a warm, illustrated how-to with numbered steps.
- `kpi-dashboard-infographic.md`: a year-in-review or "Wrapped" dashboard of big numbers.
- `legend-heavy-infographic.md`: dense explainers, cause-and-effect chains, anatomy diagrams.

In code: a page or card grid of hand-drawn panels, number badges, cartoon icons, live figures in mono, and doodles from SVG. The My finances "Illustrated" view is hand-drawn-infographic built in code.
